# 📊 Statistical Quality Control System & Patient Portal

A robust desktop application designed to bridge data science and healthcare workflow management, combining a comprehensive **Patient Portal** with an intelligent **Statistical Quality Control System** driven by **Bayes' Theorem**.

## 💡 The Challenge & Solution
In medical database systems and quality control fields, handling raw data without analytical safeguards leads to critical cascading errors. This system solves this by introducing a user-friendly desktop GUI built for secure patient data management, while simultaneously running background statistical checks. By implementing conditional probabilities (Bayes' Theorem), the system executes predictive error detection and logical validation to prevent incorrect system entry failures and data anomalies.

## 🛠️ Tech Stack & Tools
* **Core Language:** Python
* **GUI Development:** Tkinter Framework
* **Programming Paradigm:** Object-Oriented Programming (OOP)
* **Core Logic & Data Science:** Bayesian Probability, Predictive Analytics, Logic Failure Prevention

## 🌟 Key Features
* **Advanced OOP Architecture:** Built completely using Object-Oriented Programming principles to ensure clean, modular, and scalable code.
* **Interactive Desktop GUI:** Features a smooth, responsive user interface built using Tkinter for ease of data entry and navigation.
* **Bayesian Quality Control Engine:** Utilizes dynamic mathematical modeling to test data integrity and validate records based on conditional dependencies in real-time.
* **Patient Management Core:** Handles full user/patient portal entry simulations with strict data validation protocols.
